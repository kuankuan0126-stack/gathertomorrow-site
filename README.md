# Gather Tomorrow LLC — Website (v1)

This is the public website for Gather Tomorrow LLC. It's a simple one-page site hosted free on GitHub Pages. There is nothing to install or build.

## What each file does
- **index.html** — All the words on the page (hero, field notes, tools, case studies, booking form). To change text, edit this file on GitHub (pencil icon) and click "Commit changes". The site updates in about a minute.
- **assets/style.css** — The look: colors, fonts, spacing. The main colors are at the top (`--accent` is the teal highlight).
- **.nojekyll** — An empty file that tells GitHub to publish the site as-is. Leave it alone.
- **README.md** — This explanation.
